🚀 DevStart

Uma IA que ensina você a programar, em vez de programar tudo por você.

O DevStart é uma plataforma de aprendizado de programação criada especialmente para iniciantes.

A proposta é simples: o usuário apresenta uma ideia de projeto, e a IA ajuda a transformar essa ideia em algo real. Porém, existe uma regra fundamental:

A IA ajuda a construir. O usuário aprende construindo.

A plataforma não deve entregar projetos completos automaticamente. Ela deve ensinar, orientar, dar dicas e ajudar o usuário a resolver os problemas por conta própria.

🎯 O problema

Muitas pessoas que estão começando a programar utilizam IA para criar seus projetos.

O problema é que muitas vezes acontece isto:

Usuário:
"Crie um aplicativo de lista de tarefas."

IA:
"Claro!"

↓
Projeto inteiro pronto.


O usuário possui o código, mas não necessariamente aprendeu a programar.

O DevStart quer fazer diferente.

🤖 Sistema 32% / 👨‍💻 68%

Essa é a principal regra do DevStart.

🤖 IA
██████░░░░░░░░░░░░ 32%

👨‍💻 USUÁRIO
██████████████░░░░ 68%


A IA pode construir aproximadamente 32% do projeto.

Os outros 68% devem ser desenvolvidos pelo usuário.

A IA pode:
Criar a estrutura inicial.
Explicar o projeto.
Criar exemplos.
Explicar conceitos.
Criar pequenas partes de código.
Dividir o projeto em tarefas.
Dar dicas.
Analisar o código do usuário.
Explicar erros.
Sugerir melhorias.
A IA não deve:
Criar o projeto inteiro.
Entregar todos os arquivos prontos.
Resolver todas as tarefas automaticamente.
Fazer os 68% restantes pelo usuário.
Impedir que o usuário pense e tente resolver problemas.
🧠 Como funciona

O usuário começa com uma ideia.

Por exemplo:

"Quero criar um aplicativo de lista de tarefas."

A IA transforma a ideia em um plano:

📋 Lista de Tarefas

├── 1. Criar estrutura
├── 2. Criar interface
├── 3. Adicionar tarefas
├── 4. Remover tarefas
├── 5. Editar tarefas
├── 6. Marcar como concluída
├── 7. Criar filtros
├── 8. Salvar tarefas
└── 9. Testar projeto


A IA prepara o início do projeto.

Depois:

🤖 A base está pronta. Agora é sua vez.

O usuário começa a implementar as funcionalidades.

Se ficar preso, pode pedir ajuda.

🧑‍🏫 DevMentor

O DevMentor é o professor virtual do DevStart.

Ele deve agir como um mentor para iniciantes.

Em vez de simplesmente responder:

"Use addEventListener."

Ele deve explicar:

"Precisamos fazer o botão perceber quando alguém clica nele. No JavaScript existe uma forma de observar eventos, como cliques. Tente pesquisar qual método podemos usar para isso."

O objetivo é fazer o usuário entender e tentar.

💡 Sistema de dicas

Quando o usuário estiver travado, existem diferentes níveis de ajuda.

💡 Dica 1

Uma pequena pista.

💡 Dica 2

Uma explicação mais detalhada.

💡 Dica 3

Um exemplo parcial de código.

A IA deve evitar entregar imediatamente a solução completa.

🎫 Sistema de Tickets

Se a IA não conseguir ajudar o usuário, ele pode abrir um ticket.

Exemplo:

🎫 Ticket #1042

👤 Usuário:
João

📁 Projeto:
Lista de Tarefas

📍 Etapa:
Adicionar tarefa

❓ Problema:
"A IA não conseguiu me ajudar."


O ticket pode ser encaminhado para um colaborador.

Um colaborador poderá conversar diretamente com o usuário e ajudá-lo.

🧑‍💻 Sistema de colaboradores

A comunidade pode ajudar a melhorar a plataforma.

Os usuários podem evoluir dentro da comunidade:

👤 Usuário
    ↓
🧪 Testador
    ↓
🛠️ Colaborador
    ↓
🛡️ Moderador
    ↓
👑 Administrador
